Safety and fair play

Your computer, your data

Stays local

History and settings stay on your computer. The developer runs no server.

No password

Never asks for your Steam password or payment details.

No ads

No adverts, data selling or bundled extras. The website only tallies download clicks.

What leaves your computer

  • AlwaysDownloads game statistics and updatesOpenDota, Valve, GitHub
  • If you link SteamYour account number, to find public matchesOpenDota
  • If you use AI or translationYour question, game details or chat lines; a death screenshot only if you switch it on and press the buttonYour Puter account
  • If you open a team roomThe plan, cursor, Steam name, picture and account number; members can see your local network addressPeople you invite, via PeerJS and Google

Fair play

Uses

  • Dota’s own game feed, once you switch it on
  • Public statistics
  • What you type and a few game files
  • Optional: your screen during hero picks, one shot at death

Never

  • Reads game memory or network traffic
  • Clicks or types in Dota
  • Shows enemies or anything hidden
  • Sells data or charges money

Why a security warning?

The installers are not signed with a paid certificate and not certified by an outside security company, so Windows and macOS warn you.

We add no harmful or hidden software. Installers are built automatically on GitHub and each release lists a checksum. Unsure? Scan the file with your antivirus or virustotal.com. Never switch your antivirus off: tell us.
