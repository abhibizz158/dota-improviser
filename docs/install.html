Install guide

Install in minutes

Pick your computer and follow the pictures.

  1. Downloads
    Dota-Improviser-setup.exe
    Keep

    Download

    Get the installer. If asked, choose to keep it.

  2. Windows protected your PC
    More infoDon’t run

    More info

    Click More info in the blue box.

  3. Windows protected your PC
    Unknown publisherRun anyway

    Run anyway

    Then finish the installer. No administrator password.

  4. Dota Improviser
    Setup guide
    Start

    Open

    A short setup guide appears.

Permissions

  • Nothing to allow Normal use

    It runs with normal user permissions.

  • Borderless Window In Dota

    Set this in Dota’s video settings so the panel shows on top.

  • Firewall Team rooms only

    If asked, allow private networks.

  1. About This Mac
    Chip  Apple M2
    macOS 13 or later

    Check your Mac

    Needs an Apple chip: M1 or newer.

  2. “Dota-Improviser.pkg” not opened
    DoneMove to Bin

    Click Done

    Get the installer and double-click it. Do not bin it.

  3. Privacy & Security
    “Dota-Improviser.pkg” was blockedOpen Anyway

    Open Anyway

    In System Settings → Privacy & Security, scroll down.

  4. Install Dota Improviser
    Enter your password
    Install

    Install

    Then open it from Applications.

Permissions your Mac may ask for

  • Documents folder Needed

    If asked, click Allow. The app keeps its data there.

  • Screen & System Audio Recording Optional

    Only for hero reading in picks and the death screenshot. Turn on in Privacy & Security, then reopen the app. No sound is recorded.

  • After an update If you use the above

    Turn that screen permission on again.

  • Keychain AI helper only

    If asked, click Allow to keep your sign-in safe.

Check that your download is genuine

Compare your file’s code with SHA256SUMS.txt.

Mac: shasum -a 256 ~/Downloads/Dota-Improviser-*-macos-arm64.pkg
