# Public starter data

These snapshots contain public OpenDota matchup, hero, and item timing aggregates and public Valve hero kit metadata for the app's patch catalogue. They contain no account history or credentials. The desktop app reads them immediately on a fresh install. Newer successfully downloaded datasets take precedence.

To refresh the snapshots for a release, run `npm run data`, review the timestamps and hero coverage, then copy the four JSON files from `data/` here.
